# Neuresthetics Genius Study

Where do the people history remembers as geniuses stand on God, nature and law?

This repo rebuilds that public record from sources, one person at a time. **Lane A** describes what each person's sources show about God and nature — every quote located, every score capped by source quality. **Lane B** is a separate, labeled belief: that learning lawful order early may pay off. Lane A never depends on Lane B, and Lane A never pays for it.

**Why bother:** most talk about genius and belief leans on anecdotes or summary labels. Here the awkward cases stay visible — unsettled axes, single-source scores, people who name a transcendent God and still describe nature as running on law. Five independent LLM lists also disagree a lot (966 of 1,380 roster people appear on only one list). That disagreement is part of the record.

**Study page:** [neuresthetics.github.io/study](https://neuresthetics.github.io/study/)

**There are no results yet.** Nothing here supports a frequency, rate or ranking claim. Drafts are unreviewed.

Releases and past versions are listed under [History](#history). The current prerelease tag is a scaffolding detail, not the name of the study.

### Including weaker scores (sensitivity view)

The main person chart above fades any dot with certainty below 0.7, so you can see what rests on firmer ground. A second view draws the **same 88 people** at full weight — including the **42** whose best public evidence only clears 0.5 — while hollow rings still mark a single source.

That view is not a claim that weak evidence equals strong evidence. It is an illustration: the cloud of placements does not vanish when you stop visually discounting soft scores. It also marks a hard stop. Analysis is "enough" here when further reading would not move someone onto the grid or change a rule — only deepen a footnote. Complete coverage of every remembered genius is impossible; honest gaps are part of the work. Drafts only — no results yet. Lane A stays descriptive.

## Method in short

Compared with the earlier complete release ([v7.1](https://github.com/neuresthetics/neuresthetics_v7)):

- The genius roster is rebuilt from the five original model lists. It now has 1,380 people (up from 482).
- Frequency (F) is the number of distinct models that list a person (1 to 5); alias counts are not added together.
- Each person and each belief system gets its own record, with sources and a certainty grade for every fact.
- Coding scales and lists that were left open earlier (LIO axes, era buckets, regions, and related rules) are now set. Settled decisions are in [open decisions](docs/OPEN_DECISIONS.md); see [CHANGELOG.md](CHANGELOG.md) for the trail.

## How the database grows

One person per run. Each run picks the next person, researches them from primary and scholarly sources, fills their record (leaving `TODO` where nothing is sourced yet), validates it, and commits. Belief-system records are extended the same way. Michael Faraday (`people/f/faraday-michael.md`) and Pantheism (`systems/PANT.md`) are the worked examples.

```bash
pip install -r scripts/requirements.txt
python3 scripts/rebuild_roster.py --check   # roster reproduces from the raw lists
python3 scripts/assign_ids.py --check       # person ids are up to date
python3 scripts/validate_people.py          # person records
python3 scripts/validate_systems.py         # belief-system records
python3 scripts/coverage_report.py          # writes reports/coverage.md
python3 scripts/progress_status.py --check  # README progress table is up to date
pip install -r scripts/requirements-figures.txt
python3 scripts/make_figures.py             # writes figures/*.png
```
